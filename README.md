analiz.py – Satış Zaman Serisi Analizi

Bu Python dosyası, sahte satış verisiyle zaman serisi analizi yapar.  
Grafikler oluşturarak verilerin günlük, haftalık ve aylık trendlerini inceler.

Kullanılan Kütüphaneler

- pandas
- numpy
- matplotlib
- seaborn
- openpyxl (Excel için)

Üretilen Grafikler

1. Günlük satış ve hareketli ortalama (7G & 30G)
2. Aylık toplam satış bar grafiği
3. Aylara göre yıllık ortalama satış çizgi grafiği
4. Aylara göre satış dağılımı (boxplot)

Çalıştırmak için

```bash
pip install pandas matplotlib seaborn openpyxl
python3 analiz.py
